# Project name and logo

"Lakana" and the Lakana logo identify this project. The name and logo are not registered as
trade marks. The Apache-2.0 licence covers the source code; it does not grant permission to
use the name or logo (see section 6 of the licence). The one-colour mark
(`ui/src/shell/lakana-mark.svg`, also the web interface's favicon) is a simplified form of the
logo and is covered the same way.

You are welcome to use the name to state, accurately, that your software works with Lakana,
or to refer to the project in articles, talks and documentation.

If you fork Lakana or distribute a derivative, please give it its own name and logo, and do
not use ours in a way that suggests the project endorses or is affiliated with you.
