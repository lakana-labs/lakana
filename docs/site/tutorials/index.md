# Tutorials

A tutorial teaches by doing, from start to finish, for someone new.

- [Getting started](getting-started.md): install Lakana, start a local instance, build two
  tables from a project and query them. Begin here.
- [Build a table with Python](python-sample.md): create a project whose Python asset builds a
  table from SQL tables, with `lakana init --template python`, then deploy, run and query it. Do
  "Getting started" first.
- [Train a model and score with it](train-a-model.md): store a trained model as an artifact, make
  predictions with it, and look at and download the model. Do "Getting started" first.
- [Move a SQL project to Lakana](move-a-sql-project.md): convert a small project of SQL files by
  hand, with a view, an incremental table and checks, then deploy, run and query it. Do "Getting
  started" first.

More tutorials are added as they are written.
